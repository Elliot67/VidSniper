# Testing

```sh
./scripts/test.sh
```

Generates the test videos, builds, runs every test, then checks the translations. About 2 s plus the build (one to two minutes the first time). The full log is in `build/test/tests.log`. `release.sh` runs it before each release (except in GitHub Actions, where `CI` is set, or with `SKIP_TESTS=1`). Tests don't run on GitHub.

In Xcode, ⌘U runs the unit tests only (after `./scripts/make-fixtures.sh`).

## What is tested

**Swift Testing**, target `VidSniperTests`, hosted by the app (when launched by the tests, the app opens no window and registers no shortcut). Each test has a one-minute time limit, so a stuck test fails instead of hanging.

- **Unit tests**:
  - Export computations: Retina / Screen, even dimensions, 5K limit, bitrates decreasing and distinct, bitrate floor, size estimate.
  - Editing on the test video: split, split too close to an edge, delete, undo / redo, the last segment can't be deleted, extending to recover a deleted neighbour, trimming stopped by the next segment, audio tracks, clicks following the edit.
  - Preview zoom steps, time formatting.
- **Integration tests** (real export with the macOS encoder; enabled by `VIDSNIPER_INTEGRATION=1`, which `test.sh` passes through `TEST_RUNNER_`):
  - Dimensions, duration, 30 fps, audio mixed into one track.
  - BT.709 / sRGB color tags, and **the same colors as the source** (a scaled-down frame compared channel by channel).
  - Lighter levels give smaller files.
  - Minimal imported video, and the real reference recording.
- **Translations**: `scripts/check-translations.py` compares the texts extracted by the compiler with the catalog (a missing or unused French translation fails).

## Test videos

- Generated by ffmpeg (`scripts/make-fixtures.sh`, ~1 s) into `build/fixtures`, not versioned:
  - `recording.mov`: like a recording, HEVC 1280 × 720, 60 fps, 3 s, SMPTE color bars tagged like the app, frame counter, two audio tracks (440 / 880 Hz).
  - `imported.mp4`: H.264 without a color tag, one audio track. Imported videos only get minimal checks: the app mostly targets its own recordings.
- A **real reference recording** made with the app, versioned: `VidSniperTests/Fixtures/reference.mov`. It must be the raw recording (from `~/Library/Caches/VidSniper/Recordings/`), not an export.

## Rejected

- Screenshot (snapshot) tests: they break with every macOS update.
- UI tests driving the app: slow, blocked by the permissions.
- External test videos (Mediabunny, Chromium): mostly container edge cases handled by AVFoundation, and unclear licenses for the footage.

## Bugs found by the first tests

- The export stayed at 60 fps (see [Export](export.md#encoding)).
- The audio analysis froze the app when several videos were opened (see [Editor](editor.md#audio-levels-and-balance)).
- An export started after closing the editor (see [Export](export.md#live-export)).
